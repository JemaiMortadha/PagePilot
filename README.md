# 🚀 PagePilot

A 100% free, fully autonomous AI pipeline that scrapes competitor Facebook pages, rewrites text, generates custom AI images, and auto-publishes to your page.

Designed to run continuously on free-tier APIs, this script uses **Apify** for scraping, **Google Gemini** for OCR and intelligent text rewriting, **Pollinations.ai** for free AI image generation, and the **Facebook Graph API** for automated publishing.

---

## ✨ Features
- **100% Free to Run:** Operates entirely within the free tiers of Apify ($5/mo), Gemini (1500 req/day), and Pollinations (unlimited).
- **Auto-Cleanup:** Automatically deletes generated images from your hard drive after successful publishing to save space.
- **Run Anywhere:** Run it on your local PC in an infinite loop, or host it for free via GitHub Actions on a schedule.
- **Smart Deduplication:** Remembers what it has posted across different competitor pages using a persistent database (`seen_posts.json`), ensuring you never double-post.
- **AI-Powered:** Uses Gemini Vision to read text directly off competitor images (OCR), rewrites the facts to make them engaging, and generates stunning custom backgrounds.
- **Daily Gmail Reports:** Automatically emails you the status of the pipeline and tracks your API quota health so you never get surprised by limits.

## 🔑 Step-by-Step API Setup (100% Free)

You will need to fill out the `.env` file with credentials.

### 1. Gemini API (The Brains)
1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Sign in and click **"Get API Key"**.
3. Paste the key into `GEMINI_API_KEY` in your `.env`.

### 2. Apify (The Scraper)
*Note: Apify charges $0.005 per post scraped. To stay under the $5/month free tier, PagePilot is optimized to fetch exactly 1 post per page, 4 times a day.*
1. Go to [Apify](https://apify.com/) and create a free account.
2. Go to Settings > Integrations to find your API Token.
3. Paste it into `APIFY_API_TOKEN` in your `.env`.

### 3. Facebook Graph API (The Publisher)
1. Go to [Meta for Developers](https://developers.facebook.com/) and click **My Apps** > **Create App** (Select **Business**).
2. Use the **Graph API Explorer** tool. Select your App, then click "Add a Permission" and add `pages_manage_posts`, `pages_read_engagement`, and `pages_show_list`.
3. Click **Generate Access Token**. Select your Facebook Page.
4. *Important:* Extend the token in the "Access Token Debugger" to a 60-day token.
5. Paste this token into `FB_PAGE_ACCESS_TOKEN` and your Page ID into `FB_PAGE_ID`.
6. **Go Live:** Toggle your app from "Development" to "Live" in the Meta dashboard, or else your posts will only be visible to you! (You can use a blank Google Doc link for the Privacy Policy URL requirement).

### 4. Gmail Notifications (App Password)
To allow PagePilot to email you quota reports:
1. Go to your Google Account > **Security**.
2. Enable **2-Step Verification** (required).
3. Search for **App Passwords**.
4. Create a new App Password (name it "PagePilot").
5. Copy the 16-character code and paste it into `GMAIL_APP_PASSWORD` in your `.env`, and put your email in `GMAIL_ADDRESS`.

## 🚀 How to Run

### Option 1: Run Locally on Your PC (Infinite Loop)
You can run the script on your own computer. It is programmed to run a cycle, then sleep for 6 hours, and repeat forever:
```bash
python3 main.py
```
*Note: Keep your terminal open. If it closes, the script stops.*

### Option 2: Cloud Deployment via GitHub Actions (Recommended)
You can let GitHub run this script 4 times a day for free, automatically.
1. Upload this repository to GitHub (Public or Private).
2. Go to your repository **Settings > Secrets and variables > Actions**.
3. Add all the keys from your `.env` file as **Repository Secrets** (e.g., `GEMINI_API_KEY`, `APIFY_API_TOKEN`, etc.). Include `POSTS_TO_CHECK` (set to `1`) and `DEDUP_HOURS` (set to `72`).
4. GitHub Actions will automatically read `.github/workflows/schedule.yml` and run your pipeline daily at 00:00, 06:00, 12:00, and 18:00 UTC. It will safely cache your `seen_posts.json` between runs!

---

## ⚙️ Configuration Notes
- `POSTS_TO_CHECK=1`: Highly recommended to keep this at `1` to avoid exceeding the Apify monthly free limit.
- `usage_stats.json`: This file is automatically generated and tracks your API limits locally.
